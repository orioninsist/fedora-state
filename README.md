# fedora-state

Fedora system state discovery and reproducibility engine.

## Purpose

Discover installed tools and packages from a Fedora system,
generate a verified state report, and reproduce the environment
on another Fedora installation.

## Scope

Included:
- package discovery
- source detection
- verification
- restore workflow
- system reports

Excluded:
- dotfiles
- personal configuration
- backups
- user data
- accounts
